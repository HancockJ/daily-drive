# Daily Drive — product principles

1. **Clean, easy, pure.** Open the link, tap Kick off, play, share. Nothing in between.
2. **No sign-in for now.** Every feature must work for a player who never creates an account.
3. **Guest play is always the default.** If optional sign-in is ever added (see `real-stats-plan.md` on the
   `real-stats` branch), playing as a guest stays the first, default path forever — sign-in is never required,
   never a popup, and never blocks the game.
4. **The core loop is friends comparing the same day's game.** Prioritize anything that makes the daily result
   fun to share and compare; deprioritize anything that adds steps or screens.
5. **No ads, banners, or prompts during play.** If ads ever come (~1,000+ daily players), one quiet slot on the results screen only.
